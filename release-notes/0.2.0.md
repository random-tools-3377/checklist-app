Repeats your way, pacing, a recommended order, backups, and a points history.

**New**

- **Flexible repeats.** A habit can repeat every day, every few days, on chosen days of the week (every week or every other week, and so on), so many times a week, month or year, on chosen dates of the month (including the last day), on a weekday of the month like the first Monday, once a year, or just once. Every repeat can have a start date and an end date.
- **Time for a goal.** A goal can take a set length ("30 minutes"), happen at a set time ("6 pm"), have its own finish-by time, or none of these.
- **Pacing.** Set when you want to be done each day (Settings → "Finish each day's goals by"). Today then shows how much time each goal left gets and when the next one should be done. Goals with a set length keep their time; the rest share what's left evenly. "Times per week" goals with a finish day, and projects with a deadline, show a pace like "2 left · about one every 2 days".
- **Recommended order.** Today can list your goals in an order that makes them easier to get done: set times first at their time, then the earliest finish-by, then what you usually do around now, then quick ones before long ones. Switch to "My order" any time.
- **Export and import.** Settings → Backup saves everything to a file you choose, and imports it back. Phone backup stays off for this app, so this file is your backup. The same file will work on the iPhone version later.
- **Points history.** Tap your balance to see every change to it, day by day.
- **Return a reward.** Something under Bought that you haven't used can be returned for all its points back.
- **Reorder.** Use "Reorder" on the Goals and Shop screens to put things in the order you like.
- **Privacy.** The app's preview is hidden in the recent-apps screen. On phones older than Android 13 this also blocks screenshots, so there it's a switch in Settings.

**Your data from 0.1.0**

It carries over. Daily habits become "every day"; weekly and monthly habits become "so many times a week/month" with the same count.
