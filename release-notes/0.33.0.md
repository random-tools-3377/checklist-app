Goals to quit, and challenges.

**New**

- **A goal to quit.** In a habit's editor, turn on **A goal to quit** for something you want to stop, like no sugar. Its button on Today says **Avoided**: tick it each day you avoided it. A day not ticked is a miss, as usual. **I slipped** records the miss straight away and asks why; it takes back today's tick if there was one. Today shows how many days in a row you've gone without.
- **Challenges.** In a habit's editor, turn on **Challenge** and set the days in a row (30 to start with) and a bonus. Today shows how far you've got. A missed day starts it again from day 1; a skipped day doesn't count either way. The day you finish, the bonus is paid, and the habit carries on as before. **Start again today** in the editor begins a new one.

**Good to know**

- Backup files made by this version can't be read by older versions of the app.

**Installing**

Download `checklist-0.33.0.apk` below on the phone and open it. It installs over the earlier version and keeps your data.
